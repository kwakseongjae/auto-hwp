# benchmarks/local — 내 공문서로 조판 격차 재기

이 폴더에 **자기 손에 있는 .hwp / .hwpx** 를 넣고 아래를 실행하세요.

```bash
scripts/bench-local.sh
```

## 무엇을 재나요

한/글은 파일 안에 **자기가 조판한 결과**(lineseg — 문단별 줄 수와 줄 좌표)를 같이 저장합니다.
`bench-local.sh` 는 그 저장값을 정답지로 삼아 auto-hwp 의 조판과 대조합니다.

- **쪽수** — 우리 페이지 수 vs 한/글이 낸 페이지 수
- **본문 줄수** — 문단마다 줄 나눔이 같은지 (정확 일치 · ±1 이내)
- **셀 줄수** — 표 셀 안 문단의 줄 나눔

한/글 설치본도, 인터넷도, 계정도 필요 없습니다. 정답지가 파일 안에 있기 때문입니다.

## 프라이버시

- 이 스크립트는 **네트워크를 쓰지 않습니다.** 문서는 이 컴퓨터를 벗어나지 않습니다.
- 이 폴더는 `.gitignore` 로 커밋에서 제외됩니다 — 이 README 만 추적됩니다.
- 스윕 리포트(`REPORT-YYYY-MM-DD.tsv`)도 여기 떨어지므로 함께 무시됩니다.
- **이슈에는 문서를 첨부하지 마세요.** 수치·구조 특징만 올립니다
  (스크립트가 붙여넣기용 마크다운을 만들어 줍니다).

## 판정 읽는 법

| 판정 | 뜻 | 다음 행동 |
|---|---|---|
| `일치` | 쪽수 동일 + 본문 줄 정확 일치 98.9%+ | 없음 (게이트 기준선 통과) |
| `줄격차` | 쪽수는 맞는데 문단 줄 나눔이 다름 | 조판 정밀도 이슈 — 폭 계산·글자 메트릭 축 |
| `쪽격차` | 페이지 수가 다름 | 영향 가장 큼 — 세로 공간 계산 축 |
| `오라클없음` | 파일에 한/글 lineseg 캐시가 없음(변환·정규화본) | 점수를 매기지 않음. 원본 .hwp 로 다시 재 보세요 |
| `실패` | 파싱/조판 자체가 실패 | 조판 이슈가 아니라 **버그 리포트** 감입니다 |

## 다른 축도 재고 싶다면

```bash
scripts/bench-local.sh --pipeline    # "크래시 없이 파이프라인 통과하는가"
                                     # (detect / own-render / export-pdf / extract-text)
scripts/bench-local.sh --dir <경로>   # 다른 폴더를 잰다
scripts/bench-local.sh --help
```
