# 오토한글(auto-hwp) 오픈소스 공개 베타

AI가 한글을 이해하고, 수정하고, 마침내 정복할 수 있는 미래를 향한 공개 베타입니다. 지금은 더 많은
코드보다 서로 다른 실제 문서의 긴 꼬리를 함께 찾는 일이 중요한 단계입니다.

## 가장 가벼운 기여 방법

1. [autohwp.com](https://autohwp.com)에서 문서를 엽니다.
2. 브라우저 화면을 한/글·한컴독스와 비교합니다.
3. 편집 화면의 **레이아웃 문제 제보**를 눌러 다른 쪽과 증상만 알려 주세요.

문서 원본은 문서 처리 서버로 업로드되지 않습니다. 제보 초안에도 파일명·본문·해시·바이트가 자동으로
들어가지 않습니다. 공개 GitHub 이슈에 직접 적은 내용은 GitHub에 남으므로 비공개 문서와 개인정보는
첨부하지 마세요.

AI 편집은 명시적으로 동의한 뒤 필요한 문맥을 OpenRouter로 전송합니다. 오토한글(auto-hwp)은 원본,
전송된 문맥, AI 응답을 자체 데이터베이스나 스토리지에 저장·보유하지 않습니다.

## 이번 베타의 범위

- 브라우저 HWP/HWPX 렌더, 수동 편집, HTML/PDF/HWPX 내보내기
- Intent 미리보기→사용자 승인→undo를 따르는 선택적 AI 편집
- React SDK, headless editor core, MCP/CLI/서비스 컨테이너
- 에이전트가 `/llms.txt`와 Docs를 읽고 연동을 시작하는 복사용 프롬프트

## 알려진 한계

- `.hwp → HWPX`의 자동 번호·글머리표, 수식·도형, 머리말·꼬리말은 아직 완전하지 않습니다.
- HWPX 차트는 원본 패키지에 보존돼도 화면에서 사라질 수 있고 PDF 수식·차트는 자리표시자입니다.
- `.hwp` 재저장 구현은 실험적이며 한/글·한컴독스 실물 검증 전까지 공개 지원에서 제외합니다.
- 공개 데모 AI의 rate limit은 이번 베타에서 인스턴스별 메모리 카운터입니다. durable 전역 비용 상한은
  아직 없으며, Upstash 연결 뒤 별도 게이트로 닫습니다.

잘 안 되는 문서는 실패가 아니라 지금 가장 필요한 지도입니다. 문서 하나로 가볍게 참여해 주세요.
