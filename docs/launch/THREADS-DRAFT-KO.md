# 첫 Threads 게시물 초안 — 집단지성 베타

> 상태: 소유자 카피·시각 방향 승인(2026-08-12). 실제 게시 직전 링크와 라이브 화면만 최종 확인한다.
> 표기 규칙: 제품명은 항상 **오토한글(auto-hwp)**.

## 1/6 — 훅

오토한글(auto-hwp)은 아직 베타입니다.

그런데 이제는 몇 명이 더 코드를 짜는 것보다, 서로 다른 한글 문서를 가진 사람들이 한 번씩 열어 보는
편이 더 큰 도움이 되는 지점에 왔습니다. AI가 한글을 이해하고, 수정하고, 마침내 정복할 수 있는 미래를
집단지성으로 같이 만들어 보고 싶습니다.

미디어: `assets/launch/thread-community-beta.png`

## 2/6 — 1분 기여

방법은 가볍습니다.

1. https://autohwp.com 에서 문서를 엽니다.
2. 브라우저 렌더와 내가 아는 한/글 화면을 비교합니다.
3. 다르게 보이면 편집 화면의 **레이아웃 문제 제보**를 누릅니다.

파일을 공개할 필요는 없습니다. 몇 쪽에서 표·줄바꿈·글꼴 중 무엇이 다른지만 GitHub 이슈로 알려
주셔도 진짜 컨트리뷰션이 됩니다. 문서마다 다른 엣지 케이스를 발견하는 일 자체가 꽤 재미있을 거예요.

미디어: `docs/assets/launch-layout-report.png` — 실제 8쪽 HWP 렌더와 **레이아웃 문제 제보** 버튼

## 3/6 — 왜 에디터와 LLM까지 만드는가

우리가 웹 렌더러에서 멈추지 않고 에디터와 LLM 연결까지 같이 만드는 이유도 여기에 있습니다.

문서를 눈으로 보고 → 고칠 곳을 선택하고 → AI 제안을 카드로 확인하고 → 적용하거나 되돌리는 전 과정이
한 코어 위에 있어야, 사람과 에이전트가 같은 문서를 두고 같이 학습할 수 있기 때문입니다.

미디어: `assets/launch/live-contribution-flow.mp4` — 랜딩 기여 안내→예시 문서→실제 렌더 20초 화면 녹화

## 4/6 — 데이터 경계

문서를 열고, 렌더하고, 수동 편집하고, 내보내는 기본 경로는 브라우저의 Rust/wasm 엔진에서 끝납니다.
문서 파일은 오토한글(auto-hwp) 서버에 업로드되지 않습니다.

AI 편집을 켜면 필요한 문맥은 동의 뒤 OpenRouter로 **전송됩니다**. 하지만 오토한글(auto-hwp)은 원본
문서, 전송된 문맥, AI 응답을 자체 데이터베이스나 스토리지에 저장·보유하지 않습니다. 남용 방지용
IP·날짜별 횟수 키만 약 25시간 남고 문서 내용은 들어가지 않습니다.

GitHub에 직접 작성한 공개 제보는 GitHub에 남으니, 파일명·본문·개인정보·비공개 문서는 올리지 말아 주세요.

미디어: `assets/launch/thread-local-first-boundary.png`

## 5/6 — 아직 잘 안 되는 것

베타인 만큼 한계도 먼저 공개합니다.

- HWPX 내보내기와 HWPX 원본의 편집→재열기 회귀 테스트는 통과합니다.
- 다만 `.hwp → HWPX` 변환에서는 자동 번호·글머리표, 수식·도형, 머리말·꼬리말이 아직 완전하지 않습니다.
- HWPX 차트는 원본 패키지에 보존돼도 화면에서 사라질 수 있고, PDF의 수식·차트는 아직 자리표시자입니다.
- `.hwp`로 다시 저장하는 기능은 실험적이며 한컴 실물 검증 전에는 공개 지원하지 않습니다.

잘 안 되는 문서가 실패가 아니라, 지금 우리가 가장 찾고 싶은 지도입니다.

미디어: `assets/launch/live-landing-contribution.png` — 실제 베타 랜딩의 집단지성 기여 안내

## 게시 직전 수동 확인

- autohwp.com에서 비민감 `.hwp` 샘플을 열고 **레이아웃 문제 제보** 버튼이 새 GitHub 초안을 여는지 확인
- 초안 URL·본문에 파일명·문서 본문·해시가 없는지 확인
- `/privacy`, `/llms.txt`, `/docs/llm`, `/docs/embed`가 200인지 확인
- Threads가 MP4를 재생하는지 확인하고, 재생하지 않으면 `docs/assets/launch-layout-report.png`로 교체
- HWPX 한계 문구가 해당 릴리스의 실제 상태와 같은지 확인
