# HWP5 재저장 v1 — 한/글·한컴독스 수동 수용 검증

> 이슈 082의 마지막 외부 게이트. 자동 검증(rhwp 재파싱·strict CFB·스트림/섹터 diff)을 통과해도
> 한컴의 데스크톱/클라우드 파서가 실제로 여는지 별도로 확인한다. 공개 `sample-8p`만 사용하고
> 실데이터·개인정보 문서는 업로드하지 않는다.

## 자동 게이트 상태 (2026-08-11)

`scripts/verify-local.sh --full`과 082 전용 테스트는 통과했다. 로컬 수동 확인용 편집본은
`target/issue-082-manual/sample-8p-082-edited.hwp`에 생성했으며, 첫 단순 본문 문단 끝에
`[MCP-082]`를 추가한 공개 샘플이다. 크기는 67,584B, SHA-256은
`98fd6b9167d835eaa135980e04db550b8fc5f5201545a72695e3ceacc8bf56b6`다. 이 산출물은
PrvText/PrvImage의 해제 섹터까지 0으로 덮어써 편집 전 preview 바이트를 남기지 않는다.

## 검증 산출물 준비

1. `hwp-mcp`를 `--features rhwp`(서비스 이미지는 `rhwp pdf`)로 빌드한다.
2. `benchmarks/benchmark.hwp`를 연다. 이 파일은 앱의 `sample-8p.hwp`와 SHA-256이 동일한 정본이다.
3. 텍스트 전용 편집 하나를 적용한다. 표/행/열/이미지/문단 구조는 바꾸지 않는다.
4. `hwp_export_capability {}`가 `"capability":"text_patch"`인지 확인한다.
5. `export_hwp {"path":"…/sample-8p-082-edited.hwp"}`로 **새 경로**에 저장한다. 원본 위에
   덮어쓰지 않는다. 응답의 `capability_report`, `strategy`, 바이트 수를 보관한다.
6. 대조용으로 무편집 세션도 저장하고 `cmp` 또는 `shasum -a 256`으로 원본과 바이트 동일인지 확인한다.

자동 회귀만 다시 실행하려면:

```bash
cargo test -p hwp-hwp5-patch --lib -- --nocapture
cargo test -p hwp-mcp --features rhwp hwp5_op_bus_edit_exports_through_mcp_and_structural_edit_refuses -- --nocapture
```

## 한/글 데스크톱

1. 원본과 편집본을 각각 연다. "복구/손상된 문서" 경고가 없어야 한다.
2. 편집 대상 문단(중첩 셀 검증이면 해당 leaf 셀)의 새 텍스트가 보이는지 확인한다.
3. 앞·뒤 문단, 표 병합/테두리, 페이지 수가 원본과 같은지 눈으로 대조한다.
4. 파일 속성/미리보기에서 편집 전 민감 텍스트나 오래된 첫 페이지 이미지가 노출되지 않는지 확인한다.
5. 편집본을 다른 이름으로 다시 저장하고 닫은 뒤 재개방한다. 경고 없이 열리고 새 텍스트가 유지돼야 한다.

## 한컴독스

1. 새 문서를 만들지 말고 편집본 `.hwp`를 업로드해 연다.
2. 변환 실패·복구 안내 없이 편집 화면까지 진입하는지 확인한다.
3. 편집 텍스트, 대상 셀, 표 구조, 페이지 수를 원본 업로드 결과와 대조한다.
4. 가능하면 한컴독스에서 다시 `.hwp`로 내려받아 한/글 또는 한컴독스에서 한 번 더 연다.
5. 서비스가 생성한 썸네일/검색 텍스트에 편집 전 값이 남지 않았는지 확인한다.

## 실패 판정과 기록

아래 중 하나면 실패다: 열기/변환 거부, 복구 경고, 편집 텍스트 누락, 표 구조 손상, 편집 전
PrvText/PrvImage 노출. 원본·산출물 SHA-256, 사용한 앱/버전, 날짜, 오류 문구와 화면 캡처를 남기되
문서 내용에 개인정보가 있으면 공유하지 않는다.

| 날짜 | 환경/버전 | 파일 SHA-256 | 열기 | 편집 반영 | 구조/쪽수 | 미리보기 누수 | 비고 |
|---|---|---|---|---|---|---|---|
| 대기 | 한/글 또는 한컴독스 | 대기 | ☐ | ☐ | ☐ | ☐ | 사용자 실물 검증 필요 |

## 의도된 거부도 함께 확인

같은 세션에서 행 추가·열 너비 변경·이미지 삽입 같은 구조/서식 편집을 하나 적용한 뒤
`hwp_export_capability`를 호출한다. `unsupported`와 "HWPX 또는 PDF" 권고가 나와야 하며,
`export_hwp`는 오류로 끝나고 출력 파일을 만들면 안 된다.
