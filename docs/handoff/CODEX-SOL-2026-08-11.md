프롬프트는 모델 중립(AGENTS.md 규율 기준)이라 codex에 그대로 붙여넣으면 된다.

## 공통 인수인계 절차 (모든 이슈 착수 전 1회)

1. `bash scripts/context_restore.sh` → `docs/CURRENT_STATE.md`로 현재 위치 복원.
2. `AGENTS.md` 필독 — 특히 불변식 다이제스트(게이트 8/18/24/6·LOCKSTEP·rhwp 파싱 전용·
   px↔HWPUNIT·커밋/푸시는 명시 요청 시에만)와 함정 top 6.
3. 베이스라인 확인: `scripts/verify-local.sh` (quick) EXIT=0 인지 — **깨진 채 시작 금지**
   (깨져 있으면 내 변경 탓인지 구분 불가). crates 접촉 이슈는 종료 시 `--full`.
4. 종료 규율: `docs/CURRENT_STATE.md` 갱신(보고보다 먼저) + `docs/JOURNAL.md` 맨 위 5줄 항목.
   커밋은 논리 단위로 로컬에서, **푸시는 사용자 확인 후**.
