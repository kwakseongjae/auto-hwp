## 0. 왜 블로그인가

- **검색 표면이 얇다.** 제품 페이지(15 URL)만으로는 색인이 더디다 — Google 하위 URL
  pending, Brave 제출 5일차 0건(#33 증거). HWP 포맷 분석·조판 연구 같은 롱테일 질의는
  제품 페이지가 아니라 **글**이 받는다.
- **재료가 이미 레포에 있다.** `docs/research/rhwp-landscape-2026-08.md`(조판 오라클 비교),
  claw-hwp 분석, HWP5 재저장 여정(082), 중첩 표 분할, HWPUNIT/px 이원화 — 바깥에 없는
  1차 자료다. CONTENT-BRIEF §게시물 세트 1(한국어 장문 정본)도 "블로그 공용"을 이미 전제했다.
- **신뢰 서사.** "한계를 먼저 말한다" 원칙의 실행 채널 — 잘 안 되는 것의 원인 분석 글이
  곧 기여자 온보딩 문서가 된다.

## 1. 원칙

- 사용자 문서·문서 콘텐츠·비식별 실패 사례라도 **원문 캡처 게시 금지** — 구조 재현 픽스처와
  공개 샘플(sample-8p 등)만 쓴다.
- CONTENT-BRIEF 허용/금지 주장 표를 글마다 적용한다("한컴과 100% 호환" 금지 등).
- 코드·벤치 수치는 재현 커맨드와 함께 싣는다(주장을 재현할 수 있다 원칙).
- 제품명 표기: **오토한글(auto-hwp)**.

## 3.1 B2 진입 게이트 (2026-08-20 인터뷰 확정)

행동 지표를 게이트로 쓴다 — 발행·색인 제출만으로 트랙을 닫지 않는다.
- 유기 지표의 **정본은 GSC 클릭/노출**이다(GA4는 동의 게이트라 구조적 과소계상).
- 기여 전환은 #62에서 정의할 **블로그용 outbound 이벤트**로 측정한다(기존 GA4 이벤트 6종에 outbound·GitHub 클릭이 없다).
- 임계치는 **제안값**이며 **B1 첫 글 머지 전 소유자 확정**: 8주 관측에 유기 100+ / referral 20+ / 기여 액션 5+ 중 2개.
- 미달 시 원인 판정 리뷰(색인 미완 / 주제 부적합 / 유통 부재) 후 **유통 보강 또는 중단·축소**를 명시한다 — 게이트가 실제로 의사결정을 바꾸게. 시한까지 미확정이면 B1은 진행하되 B2 진입 보류 + CURRENT_STATE에 pending 기록(#33 선례).
